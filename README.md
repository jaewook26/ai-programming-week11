## ① 무엇을 하나요 (What)

<!-- 한 문장으로. "성적 CSV를 읽어 유효한 점수만 골라 냅니다." 처럼. -->

성적 CSV에서 유효한 점수는 읽고, 잘못된 행은 이유와 함께 기록합니다. AI가 작성한 테스트와 직접 작성한 테스트를 비교하고, 고장 난 최고점 계산 함수의 버그도 테스트로 확인합니다.

## ② 왜 만들었나요 (Why)          ★ AI는 이 칸을 못 씁니다

테스트가 프로그램의 오류를 실제로 찾아내는지, 그리고 코드만 보고 만든 테스트와 명세만 보고 만든 테스트가 어떻게 다른지 확인하기 위해 만들었습니다. 특히 경계값과 잘못된 입력을 테스트해야 버그를 놓치지 않는다는 점을 연습합니다.
